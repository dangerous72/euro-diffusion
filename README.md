# Euro Diffusion

Лабораторна робота №1 «Інспекції програмного коду».

Програма моделює поширення євро-монет між містами Європи. Кожне місто - клітинка сітки 10 x 10,
кожна країна - прямокутник із міст. Спочатку в кожному місті 1 000 000 монет своєї країни.
Щодня місто відправляє кожному сусідові по 1 монеті з кожної 1000 монет кожного мотиву.
Для кожної країни програма визначає, через скільки днів у всіх її містах з'являться монети всіх країн.

## Запуск

```
python euro_diffusion.py < input.txt
```

Результат для `input.txt`:

```
Case Number 1
Spain 382
Portugal 416
France 1325
Case Number 2
Luxembourg 0
Case Number 3
Belgium 2
Netherlands 2
```

## Тести

```
python -m unittest -v
```
